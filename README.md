# 🧠 MindFlow — Персональный «Второй Мозг»

> Сверхбыстрый, минималистичный и чистый личный сервис для заметок и ежедневного планирования. Создан как бескомпромиссная альтернатива «Избранному» в Telegram, Notion и Apple Notes.

---

## ⚡ Особенности и возможности

### 1. 📥 Быстрый инбокс (Quick Capture)
- **Всегда под рукой:** Строка быстрого ввода закреплена сверху.
- **Умное распознавание:**
  - Если строка начинается с `[] `, `[ ] `, `- [ ]` или `- `, она автоматически распознается как **Задача**.
  - Автоматически выявляет внешние веб-ссылки (`https://...`, `http://...`) и делает их удобными кликабельными карточками/пиллами.
  - Автоматически выявляет `#теги` (на русском и английском) прямо из текста.
  - Ручной выбор режима (Авто / Задача / Заметка).
  - Настройка срока (Сегодня, Завтра, Без даты) и приоритета (Низкий, Средний, Высокий).
  - Быстрый переход в инбокс клавишей `/`.

### 2. 📅 Ежедневник (Daily Planner)
- **Фокус на сегодняшнем дне:** Блок «Сегодня» с прогресс-баром выполнения дня (`X из Y выполнено • %`).
- **Празднование завершения:** При выполнении 100% задач на сегодня запускается приятная микро-анимация конфетти (`canvas-confetti`).
- **Перенос невыполненного на завтра в 1 клик:** Кнопка «Перенести невыполненное» мгновенно сдвигает все просроченные и незавершенные задачи на завтра с красивым уведомлением.
- **Тактильные чекбоксы:** Мгновенный отклик, анимация галочки и зачеркивания текста.
- **Удобная фильтрация:** «Все», «Сегодня», «Завтра», «Без даты», «Выполненные».
- **Архив:** Просмотр завершенных дел с возможностью очистки.

### 3. 📝 Заметки и база знаний (Notes)
- **Поддержка Markdown:**
  - Заголовки `# H1`, `## H2`, `### H3`
  - Форматирование: `**жирный**`, `*курсив*`, `~~зачеркнутый~~`
  - Списки: маркированные `- `, нумерованные `1. ` и чек-листы `- [ ] `
  - Блоки кода с подсветкой и моноширинный инлайн-код `` `code` ``
  - Цитаты `> Цитата`
  - Ссылки `[Название](https://...)` и автолинкинг
- **Закрепление (Pin):** Важные заметки крепятся на самом верху.
- **Режимы редактора:** «Редактор», «Превью» и «Сплит» (для широких экранов).
- **Счетчики:** Количество слов, символов и список обнаруженных тегов.

### 4. 🏷️ Умные теги (#теги)
- Пишите `#тег` в любом месте заметки или задачи (например, `#work`, `#идеи`, `#книги`, `#срочно`).
- Все теги автоматически группируются в боковом меню с отображением счетчика упоминаний.
- Клик по тегу моментально фильтрует всё рабочее пространство.

### 5. ⚡ Мгновенный поиск и командная палитра (`Cmd / Ctrl + K`)
- Вызов по `⌘K` или `Ctrl+K`.
- Мгновенный сквозной поиск по всем задачам, заметкам и тегам.
- Быстрые команды: создание новой заметки (`⌘N`), перенос задач на завтра, переключение темы, вызов бэкапа.
- Полная навигация с клавиатуры (`↑`, `↓`, `Enter`, `Esc`).

### 6. 🎨 Дизайн и темы
- **Минимализм:** Вдохновлен эстетикой Linear, Notion и Apple Notes.
- **Глубокая темная тема:** Насыщенный темный фон (`#09090b`), мягкие контрасты, акцентная индикация.
- **Светлая тема:** Чистый журнальный стиль с безупречной типографикой (шрифт *Plus Jakarta Sans* / *Inter*).
- **Авто-тема:** Определение системных предпочтений OS с возможностью переключения в один клик.
- **Адаптивность и PWA-ready:**
  - Оптимизирован под мобильные устройства: нижняя панель навигации (Bottom Bar) для удобного управления большим пальцем.
  - Манифест PWA (`manifest.webmanifest`), мета-теги iOS и векторная иконка.

### 7. 🔒 Локальность и Бэкап
- Все данные сохраняются моментально в `localStorage` браузера (никаких сторонних серверов или трекеров).
- **Экспорт в JSON:** Полный архив всех задач, заметок и истории.
- **Экспорт в Markdown:** Выгрузка всей базы заметок в единый чистый `.md` файл.
- **Импорт JSON:** Возможность восстановить данные или объединить их с существующими.

## ⌨️ Горячие клавиши

| Сочетание | Действие |
| :--- | :--- |
| `⌘ / Ctrl + K` | Глобальный поиск и командная палитра |
| `⌘ / Ctrl + N` | Создать новую заметку |
| `⌘ / Ctrl + B` | Свернуть / развернуть боковое меню |
| `/` | Сфокусироваться на верхней строке инбокса |
| `Enter` | Сохранить задачу или мысль в инбоксе |
| `Esc` | Закрыть модальное окно или отменить поиск |
| `⌘ / Ctrl + /` | Открыть справку по горячим клавишам |
